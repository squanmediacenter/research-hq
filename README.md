# The Architect of Inquiry — Student Research Tools

Three self-contained, browser-based tools that guide students through research as detective work, built for the **Charles Raffetto Media Center** at Manasquan High School.

- **Investigator's Pledge** — take the oath and commit to the Rules of Evidence
- **Question Quest** — sharpen a hunch into a question worth investigating
- **Source Hunt** — track down credible sources and legally get past paywalls

The tools run entirely in the browser — no login, no server — and a student's saved work carries across all three.
